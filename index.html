50 Startups: CRISP-DM Machine Learning Project Log

Objective: Build a robust, self-documenting Machine Learning pipeline to predict startup profitability based on spending profiles, adhering strictly to the CRISP-DM methodology.
Dataset: 50 Startups Records: 50 Features: R&D, Admin, Marketing, State Target: Profit Output: startup_profit_model.pkl
1

Data Acquisition & Sourcing

Sourced the classic 50 Startups dataset from open-source repository. Verified exactly 50 records. Features: R&D Spend, Administration, Marketing Spend, State (Categorical), Profit (Target Variable).

2

CRISP-DM Step 1 — Business Understanding

Predict startup net profit from expenditures and location. Help venture capitalists identify startups with the highest mathematical potential for profitability.

3

CRISP-DM Step 2 — Data Understanding (EDA)

Dataset shape (50, 5). Missing values: None. Duplicate records: None. Key findings: R&D Spend ↔ Profit correlation 0.97; Marketing Spend ↔ Profit correlation 0.75; Administration correlation 0.20.

4

CRISP-DM Step 3 — Data Preparation

OneHotEncoder on State (drop="first" to prevent dummy variable trap). StandardScaler applied to continuous features. 80/20 train/test split with fixed random seed for reproducibility.

5

CRISP-DM Step 3.11 — Advanced Feature Selection Analysis

Comparison across Pearson Correlation, SelectKBest (F-Regression), RFE, Lasso Regularization (L1), and Random Forest Importance. Conclusion: R&D Spend is dominant (~92.2% importance), Marketing Spend is secondary (~5.1%), Administration and State add negligible predictive power.

6

CRISP-DM Steps 4 & 5 — Modeling & Evaluation

Fitted Multiple Linear Regression via OLS. Parsimonious 2-feature model achieves optimal sweet spot (Test RMSE: $8,198.80, R² Score: 0.9474), outperforming full 5-feature model (overfitting cliff at $9,137.90).

7

CRISP-DM Step 6 — Deployment

Model serialized via pickle (.pkl) and gzip (.pkl.gz). Interactive client-side web application hosted on GitHub Pages with instant predictions and parameter tuning.
